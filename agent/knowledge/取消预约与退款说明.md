# 医联智诊取消预约与退款说明

> 适用范围：医联智诊学习项目中的模拟知识资料。不同医院、支付渠道和就诊项目的取消时限、退款条件、到账时间可能不同，实际结果以平台页面、医院规则和支付渠道通知为准。

## 1. 什么情况下可以申请取消

患者无法按时就诊时，应尽早在“我的预约”中查看是否可以取消。能否取消由预约状态、就诊日期、医院规则和是否已经签到等条件共同决定。

以下情况通常不能直接取消，或者需要联系医院人工处理：

- 已经签到或进入排队。
- 医生已经接诊或预约已经完成。
- 已超过平台规定的取消时限。
- 订单正处于退款中或其他处理中状态。

## 2. 取消预约流程

1. 打开“我的预约”。
2. 选择需要取消的预约，核对预约编号、医生和就诊时间。
3. 点击取消预约，阅读取消及退款提示。
4. 再次确认后提交。
5. 返回预约详情查看最新状态。

通过智能助手取消预约时，助手会先展示待取消的预约信息，并要求患者确认。患者选择“再想想”时，不会执行取消操作。

## 3. 取消和退款不是同一件事

- 未支付预约取消后，一般不涉及退款。
- 已支付预约符合退款条件时，取消成功后可能进入退款流程。
- 显示“退款中”表示退款尚未完成，不应重复提交取消或退款请求。
- 退款成功时间取决于医院结算流程和原支付渠道。

平台显示取消成功，并不代表款项已经即时到账。患者应继续查看支付详情或原支付账户。

## 4. 取消失败怎么办

先查看系统给出的失败原因和预约当前状态。不要连续快速重复提交，以免造成重复请求。如果状态长时间没有更新，可以通过平台客服或医院窗口咨询，并提供预约编号。

## 5. 注意事项

- 取消前务必核对预约编号，避免取消错误的预约。
- 多次无故爽约可能受到医院预约规则限制，具体以医院规定为准。
- 不要向智能助手或陌生人提供银行卡密码、短信验证码等敏感信息。
- 退款金额与到账时间以实际支付记录为准，知识库不能替代支付系统结果。
