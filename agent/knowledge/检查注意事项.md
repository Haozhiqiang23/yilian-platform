# 常见检查注意事项

> 重要提示：本文只用于医联智诊学习项目的知识检索演示，不能替代医生或检查科室针对患者开出的准备要求。同一种检查因检查部位、是否增强、患者年龄及基础疾病不同，准备方式可能不同，必须以检查申请单和医护人员通知为准。

## 1. 通用准备

- 按预约时间到达检查科室，携带检查申请和有效身份信息。
- 提前告知医护人员过敏史、怀孕或备孕情况、肾功能异常及重要基础疾病。
- 是否空腹、饮水、憋尿或停用药物，应严格遵照医嘱，不要自行决定。
- 检查前去除检查部位附近的金属物品。
- 儿童、行动不便或不能配合检查的患者，应提前咨询是否需要家属陪同或特殊安排。

## 2. CT 检查

- 检查前去除检查部位的金属饰品和其他可能产生伪影的物品。
- 头部、四肢等普通 CT 通常不要求空腹，但应以检查通知为准。
- 腹部、盆腔或增强 CT 可能要求空腹、饮水或憋尿。
- 增强 CT 使用对比剂前，应主动说明既往对比剂过敏、肾功能异常等情况。
- 检查中或检查后出现呼吸困难、皮疹等不适，应立即告知医护人员。

## 3. MRI（磁共振）检查

- 进入检查区域前，应去除手机、银行卡、钥匙、硬币、首饰等金属或电子物品。
- 有心脏起搏器、电子耳蜗、金属植入物、血管夹等情况时，必须提前告知医护人员，由专业人员判断是否可以检查。
- 有幽闭恐惧、不能平卧或无法保持安静等情况时，应提前沟通。
- 不要仅凭“植入物是以前安装的”自行判断安全性。

## 4. 超声检查

- 腹部超声可能要求空腹，并避免进食容易产气的食物。
- 泌尿系统、妇科等部分超声可能要求适量饮水并保持膀胱充盈。
- 心脏、甲状腺等检查的准备要求可能不同，应以申请单为准。

## 5. X 线检查

- 去除检查部位的金属物品及可能遮挡图像的物品。
- 怀孕或可能怀孕者应在检查前主动告知医护人员。
- 按工作人员要求保持指定体位和短暂屏气，不要自行移动。

## 6. 检查结果和报告

- 完成检查不代表报告已经生成。
- 报告生成时间由检查类型和医院流程决定。
- 影像或检验报告中的专业结论需要由接诊医生结合症状、病史和其他检查综合解释。
- 智能助手只能查询平台中的真实报告，不能自行判断病情或制定治疗方案。
