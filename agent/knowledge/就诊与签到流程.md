# 医联智诊就诊与签到流程

> 适用范围：医联智诊学习项目中的模拟知识资料。签到时间、地点、迟到处理和排队规则以医院现场及平台实时提示为准。

## 1. 到院前准备

- 查看预约编号、医生、科室、院区、日期和就诊时段。
- 携带患者本人的有效身份证件及就诊所需资料。
- 留意医生停诊、改期和平台通知。
- 根据路程合理安排到院时间，不必过早聚集候诊。

## 2. 到院签到流程

1. 到达医院后，通过平台、自助机或人工窗口签到。
2. 系统核对预约状态和就诊日期。
3. 签到成功后进入对应科室的候诊队列。
4. 查看排队号、前方人数或叫号状态。
5. 在候诊区域留意大屏、广播和平台消息。
6. 被叫号后前往指定诊室就诊。

智能助手办理签到前会展示预约编号并要求患者确认。只有符合签到条件的预约才能进入队列；待支付、已取消、退款中或已完成的预约不能用于签到。

## 3. 排队信息怎么看

- 排队号：本次签到产生的候诊编号。
- 前方人数：当前排在患者之前的人数，仅供参考。
- 等待叫号：已经进入队列，尚未轮到。
- 已叫号：请根据现场提示前往诊室。
- 已完成：本次排队或就诊流程已经结束。

候诊顺序可能因急诊、复诊、过号处理和现场调度发生变化。系统不能根据前方人数承诺准确的就诊时间。

## 4. 没有排队记录怎么办

可能原因包括：尚未签到、签到未成功、预约状态不符合要求、未到允许签到时间，或者现场系统尚未同步。患者可以先查看预约详情，再根据平台提示重新签到或咨询现场工作人员。

## 5. 迟到和过号

不同医院的迟到和过号处理方式不同。发生迟到或错过叫号时，不要自行判断预约已经作废，应查看平台提示或咨询分诊台，由现场工作人员安排后续处理。

## 6. 就诊安全提示

- 如出现胸痛、呼吸困难、意识障碍、大量出血等紧急情况，应立即拨打 120 或前往急诊，不要继续等待普通门诊叫号。
- 排队数据可能实时变化，请以医院现场叫号为准。
- 不要将身份证、就诊码或支付验证码交给陌生人。
