# 医联智诊预约挂号说明

> 适用范围：医联智诊学习项目中的模拟知识资料，不代表任何一家真实医院的具体制度。实际预约结果、开放日期、号源数量和费用，以平台实时页面及医院通知为准。

## 1. 预约前需要准备什么

- 使用患者本人的实名信息登录平台。
- 确认就诊人、科室、医生、就诊日期和时间段。
- 阅读医生出诊信息及号源剩余数量。
- 儿童、老年人或其他特殊就诊人，应按平台要求完善就诊人信息。

## 2. 预约挂号流程

1. 进入“医生查询”或“预约挂号”页面。
2. 按科室、医生姓名或就诊日期查询医生。
3. 查看医生详情和可预约号源。
4. 选择日期与时间段，核对医生、科室、费用等信息。
5. 确认预约；如平台要求支付，应在订单有效期内完成支付。
6. 在“我的预约”中查看预约状态和预约编号。

智能助手可以帮助查询医生、号源并生成预约操作，但创建预约前会再次请求患者确认。只有确认后，系统才会提交预约。

## 3. 分时段预约

预约号源通常按日期和时间段开放。患者应按预约时段到院，减少过早到院和长时间候诊。具体可预约范围、放号时间和停号时间由平台及医院决定。

## 4. 预约结果怎么看

- 待支付：预约可能尚未生效，需要在规定时间内完成支付。
- 已支付：支付已经完成，请按预约时间就诊。
- 已取消：预约已取消，不能继续签到。
- 退款中：退款正在处理，请关注支付渠道或平台通知。
- 已完成：本次预约对应的就诊流程已经结束。

平台状态是判断预约是否成功的依据。收到预约预览、确认提示或查询到号源，都不等于已经创建正式预约。

## 5. 注意事项

- 预约和就诊应使用同一位患者的实名信息。
- 医生出诊安排可能临时调整，请留意平台消息。
- 不要通过非官方中介购买号源。
- 急危重症不适合等待普通门诊预约，应立即拨打 120 或前往急诊。
